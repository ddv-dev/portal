# Безопасность

## Аутентификация

- Внешняя через Apache (Kerberos/NTLM)
- Laravel доверяет `REMOTE_USER`
- **Прямой доступ к PHP-FPM в обход Apache запрещён**
- Вход по логину/паролю через Laravel невозможен (`SsoGuard::validate()` всегда `false`)

## Авторизация

- **Policies/Gates в проекте отсутствуют**
- Разграничение доступа — на уровне Apache и Redmine-сервисов
- Filament-админка — открыта для всех авторизованных (проверить!)

## Загрузка вложений

`AttachmentController` — whitelist моделей:
- `news` → `App\Models\News`
- `info` → `App\Models\Info`
- `sop` → `App\Models\Sop`
- `order` → `App\Models\OrderStorage`

Роут: `GET download/{model}/{id}/{attachment}`

## Что проверить

1. **Права на Filament-админку** — кто может управлять справочниками?
2. **Проверка доступа** к `download/{model}/...` — может ли пользователь скачать вложение чужого отдела?
3. **Кто может создавать issues** в Redmine — любой авторизованный?
4. **Логирование действий** в Redmine — для аудита.

## Известные риски

| Риск | Уровень | Что делать |
|---|---|---|
| Доверие REMOTE_USER | Высокий | Убедиться, что PHP-FPM недоступен напрямую |
| Отсутствие проверки прав на download | Средний | Добавить Policy или проверку владельца |
| Filament без ограничений | Средний | Настроить доступ по ролям |
| Нет аудита Redmine | Низкий | Логировать create/update issues |
