# ADR 0003: Сервисы только для интеграций

## Контекст
Бизнес-логика портала — CRUD-админка (Filament) и простые контроллеры.
Интеграции (AD, Redmine) — сложные, требуют тестирования.

## Решение
Сервисный слой (`app/Services`) — только для интеграций.
CRUD-логика остаётся в контроллерах и Filament-ресурсах.

## Последствия
+ Меньше файлов, проще навигация
+ Интеграции изолированы и тестируемы
− При росте бизнес-логики придётся выносить её в сервисы
− Смешение стилей (часть логики в контроллерах, часть в сервисах)
