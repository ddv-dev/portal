# ADR 0001: Аутентификация через Windows SSO

## Контекст
Портал — внутренний, пользователи — сотрудники в домене M01.
Нужен вход без пароля, с автоматическим определением ФИО, отдела, email.

## Решение
Использовать Apache + Kerberos/NTLM для передачи `REMOTE_USER`.
Laravel доверяет заголовку и кладёт данные в сессию.
Данные о пользователе дополняются из AD (LDAP) и Redmine (MySQL).

## Последствия
+ Нет паролей, нет формы входа
+ Автоматическое определение ФИО и отдела
− Жёсткая зависимость от Apache и домена
− При недоступности LDAP пользователь видит логин вместо ФИО
− Прямой доступ к PHP-FPM запрещён
