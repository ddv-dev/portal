# ADR 0002: Прямые запросы к БД Redmine

## Контекст
Порталу нужны задачи, проекты, пользователи, кастомные поля Redmine.
Redmine API медленный для списков, не отдаёт всё нужное.

## Решение
Подключиться к БД Redmine напрямую через отдельное соединение `redmine`.
Запись — только в транзакции.
Загрузка файлов — через HTTP API (`/uploads.json`).

## Последствия
+ Быстрые выборки, доступ ко всем таблицам
+ Транзакции для записи
− Жёсткая связь со схемой Redmine
− При обновлении Redmine схема может поехать
− Нужно фиксировать версию Redmine при деплое
